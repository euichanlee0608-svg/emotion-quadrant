# 감정의 사분면

“기분이 안 좋다”로 뭉뚱그려지는 감정에, 좀 더 정확한 이름을 붙여 보는 웹앱.

한국어 감정단어 **434개**를 **쾌-불쾌 × 활성화** 평면에 실제 평정값 그대로 놓는다.
처음에는 「좋음–안 좋음 / 심함–약함」이라는 성긴 사분면에서 시작하고, 단어를 하나 고르면
**그 단어가 새 원점**이 되면서 보는 범위가 절반쯤으로 좁아진다. 축 이름도 그 좁아진 구간에
맞춰 다시 붙는다(예: `안 좋음 ↔ 좋음` → `참담함 ↔ 언짢음`). 이 사이클을 4~6번 돌면
원형성이 낮아 평소엔 잘 안 쓰던, 그러나 지금 상태에 더 정확한 단어에 닿는다.

단어를 한 번 누르면 뜻이 뜨고, 읽어 본 뒤 좁힐지 / 여기서 멈출지 고른다.

## 데이터 출처

박인조·민경환 (2005). 「한국어 감정단어의 목록 작성과 차원 탐색」.
*한국심리학회지: 사회 및 성격*, 19(1), 109–129.

부록 1의 감정단어 434개와 네 가지 평정값(원형성·친숙성·쾌-불쾌·활성화, 모두 7점 척도 평균)을
그대로 썼다. **뜻풀이는 이 사이트에서 붙인 것으로 논문 내용이 아니다.**

### 추출 정확도

논문 표 4가 434개 단어의 쾌-불쾌·활성화를 1점 구간별로 집계해 두었는데, 추출 결과가
**두 차원 모두 정확히 일치**한다(`source/build_data.py`가 매번 이 체크섬을 확인).

| 구간 | 쾌-불쾌 (논문 / 추출) | 활성화 (논문 / 추출) |
|---|---|---|
| 1~1.99 | 39 / 39 | 1 / 1 |
| 2~2.99 | 216 / 216 | 42 / 42 |
| 3~3.99 | 57 / 57 | 129 / 129 |
| 4~4.99 | 44 / 44 | 143 / 143 |
| 5~5.99 | 75 / 75 | 111 / 111 |
| 6~6.99 | 3 / 3 | 8 / 8 |

알려진 원문 이슈 두 가지:

- 부록에 `감홍`으로 인쇄돼 있으나 感興(**감흥**)이다. 앱에서는 교정해 표시한다.
- 논문 본문은 대표단어를 **87개**라 하는데 부록의 `*` 표시는 **86개**뿐이다. 원문 자체의
  불일치라 임의로 채우지 않았다. 대신 화면에 띄울 단어는 `*` 표시가 아니라
  **원형성(연속값)** 순으로 고른다 — 이쪽이 전수 검증된 값이다.

## 구조

빌드 도구 없는 정적 사이트. 전부 상대경로이고 백엔드가 없다.

```
index.html   마크업 + 전체 CSS + 방문 비콘
app.js       사분면 줌 엔진 (좌표 계산·단어 선택·축 라벨·배치 보정)
data.js      단어 434개 (source/build_data.py 로 생성 — 직접 고치지 말 것)
source/      논문 추출 원자료 + 뜻풀이 원본 + 생성 스크립트
tests/       엔진 회귀 테스트, 브라우저 검증 스크립트
```

### 엔진 요약 (`app.js`)

- `view = {cx, cy, rx, ry}` — 지금 보고 있는 (쾌-불쾌, 활성화) 구간.
  0단계는 원점을 척도 중립값 4.0에 두고 반경은 데이터를 딱 덮을 만큼(2.75 × 2.7).
- 단어 선택: 시야 안 · 안 지나온 단어를 사분면별로 나눠 **원형성 높은 순**으로 돌아가며 집되,
  정규화 좌표에서 최소 간격(`SEP_X`/`SEP_Y`)을 두는 것만 통과시킨다. 최대 12개.
- 배치 보정(`relaxChips`): 칩 폭은 글자 수·화면 폭에 따라 달라져 정규화 좌표만으론 겹침을
  못 막는다. 그려진 뒤 **실제 픽셀**로 보드 안에 클램프하고 겹친 쌍을 밀어 뗀다.
- 줌: 고른 단어를 새 원점으로 삼고 `rx, ry *= 0.55`.
- 종료: 다음 화면에 띄울 칩이 3개 미만이면 결과 화면으로. 보통 4~6단계.

## 검증

```bash
node --check app.js
node tests/engine_test.mjs        # 데이터 체크섬 + 배치 규칙 + 경로 순회
python3 source/build_data.py      # data.js 재생성이 재현되는지
```

브라우저 검증(헤드리스 크롬 CDP, 데스크톱 1280 + 모바일 390 두 뷰포트):

```bash
python3 -m http.server 8777 &
python3 -m venv /tmp/cdpvenv && /tmp/cdpvenv/bin/pip install websocket-client
/tmp/cdpvenv/bin/python tests/browser_check.py http://127.0.0.1:8777/index.html
```

`--window-size`는 이 Mac의 크롬에서 500px 미만으로 안 내려가므로, 진짜 390px 검증은
CDP `Emulation.setDeviceMetricsOverride`로 한다. 자세한 건 메모리
`reference-webapp-playbook` §3.

## 범위 밖

- **한/영 토글 없음.** 434개 감정단어의 미묘한 차이는 번역하면 그대로 뭉개진다.
  UI는 한국어로만 두고, 푸터에 이 앱이 뭔지 설명하는 영어 문단만 넣었다.
- 심리 검사·진단이 아니다. 감정에 이름을 붙여 보는 어휘 도구다.
